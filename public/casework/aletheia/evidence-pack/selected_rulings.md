# ALETHEIA — Selected rulings

Frozen rulings surfaced for the portfolio layer.

## GOV-002 — Prices (ENERGIA × SEPA)

```text
ENERGIA × SEPA = DESCRIPTIVE_ONLY
PRICE_QUOTE != PRICE_INDEX
ESTABLISHMENT + PRICE_QUOTE
```

Restrictions:

```text
NO DIRECT POOLING
NO COMMON PRICE LEVEL
NO ALTERNATIVE CPI
NO TRANSACTION-PRICE CLAIM
NO NATIONAL/REPRESENTATIVE COVERAGE CLAIM
```

## IPC

```text
NO AUTOMATIC SPLICE
```

Windows / discontinuities prevent assuming automatic series continuity.

## EPH

Methodological, questionnaire, classification, coverage, or measurement changes
can affect period-to-period comparability. Breaks are evaluated by evidence,
not as one equivalent class.
